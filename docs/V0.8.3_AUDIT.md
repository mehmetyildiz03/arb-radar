# v0.8.3 — Nitro-Calibrated Paper Cost Audit

Date: 2026-09-30  
Issue: #28  
Status: paper-only research

## Why this version exists

v0.8.2 proved that at least one cent-scale closed cycle could be exact-quoted with positive gross edge, while the final paper result remained negative.

Recorded v0.8.2 exact sample at block `74176592`:

- input: $0.01
- output: ~$0.0146383545
- gross edge: **+$0.0046383545**
- V4Quoter research gas: **-$0.0124053729**
- fixed extra allowance: **-$0.05**
- 1% safety margin: **-$0.0001463835**
- paper net: **-$0.0579134020**

The fixed $0.05 allowance was intentionally conservative but not calibrated to Robinhood/Nitro transaction poster/data fees. Removing it blindly would be equally invalid. v0.8.3 replaces it with a measured Nitro fee component whenever the chain exposes that measurement.

## Nitro fee component model

The engine queries the Arbitrum Nitro NodeInterface precompile at:

`0x00000000000000000000000000000000000000C8`

using `gasEstimateComponents(to, contractCreation, data)`.

The representative calldata encodes the same base asset, input amount, minimum output and V4 path shape that an atomic closed-cycle executor would need.

Returned components are interpreted as:

- `gasEstimate` — total estimated transaction gas units
- `gasEstimateForL1` — parent-chain / data component expressed in child-chain gas units
- `childGasEstimate = gasEstimate - gasEstimateForL1`
- `baseFee` — child-chain base fee
- `l1BaseFeeEstimate` — parent-chain base-fee estimate

The measured parent/data fee used by the paper model is:

`parentDataCostWei = gasEstimateForL1 × baseFee`

For v0.8.3 paper gas:

`preBufferGas = V4Quoter gas estimate + NodeInterface childGasEstimate`

then the existing 20% research buffer is applied.

This is deliberately conservative: V4Quoter gas is still a swap-execution proxy, while NodeInterface adds a representative transaction-envelope child-gas component. A real executor simulation remains the next accuracy step.

## Fallback behavior

If NodeInterface cannot be queried or returns invalid components:

- the quote is marked `costModel = legacy-fallback`
- V4Quoter gas + 20% is retained
- the previous $0.05 allowance is retained
- the fallback reason is persisted and shown in the dashboard

No failure silently becomes a cheaper quote.

## Public live evidence

### Nitro smoke with non-zero parent fee

At block `75975158`, representative 3-hop executor calldata produced:

- total gas estimate: 44,403
- parent/L1 gas component: 18,824
- child gas component: 25,579
- child base fee: 22,954,000 wei
- parent base-fee estimate: 69,060,954 wei
- calldata size: 836 bytes
- measured parent-data cost: **$0.001159284835**
- prior fixed allowance: **$0.05**

For that one live sample, the measured parent-data component was about 43× smaller than the old fixed allowance.

This ratio is **not** treated as a constant.

### Later zero-parent-fee sample

At block `75978475`, the same representative smoke path returned:

- total gas estimate: 25,537
- parent/L1 gas component: 0
- child gas component: 25,537
- base fee: 22,378,000 wei
- parent-data cost: $0

The engine therefore measures fee components per quote/run rather than applying the earlier ratio globally.

## Historical gross-positive recheck

A dedicated script attempted to query Nitro fee components for the recorded gross-positive block `74176592`.

The public Robinhood RPC returned:

`historical state ... is not available`

Therefore v0.8.3 **does not invent a historical Nitro parent-data fee** and does not claim a recalculated net result for that old block.

One conclusion is still directly supported by the recorded v0.8.2 quote: its old gas component alone, ~$0.0124, was already larger than its +$0.00464 gross edge. Correcting the arbitrary $0.05 allowance therefore does not by itself prove that historical sample would have been profitable.

## What v0.8.3 does not prove

- It does not measure the exact gas of a deployed atomic executor.
- It does not prove transaction inclusion.
- It does not turn marginal edge into executable capacity.
- It does not remove the 1% safety margin.
- It does not guarantee a positive sample.
- It does not reconstruct unavailable historical Nitro fee state.

## Next accuracy target

The remaining dominant cost uncertainty is the use of V4Quoter gas as a proxy for actual atomic execution.

The next research step should simulate real atomic-executor bytecode without broadcasting a transaction, preferably via state override / simulation RPC, and compare:

- real executor gas
- V4Quoter gas proxy
- NodeInterface child-gas overhead
- measured parent-data fee
- final same-base closed-cycle net

Only then should the paper model replace the current quoter-based execution-gas proxy.
