# v0.8 Economic Truth Engine audit

Date: 2026-09-27  
Branch: `v0.8-economic-truth`

## Why v0.8 exists

Earlier versions intentionally separated indexer screening from executable simulations, but the primary candidate funnel still began with ETH-normalized last-trade prices and used a two-router-leg research model. That was useful for timing experiments but was not the strongest representation of real multi-quote arbitrage economics.

v0.8 replaces that primary path with a closed-cycle truth model.

## Implemented

- process-level `runId`, `engineVersion`, `runStartedAtMs`
- `radar_runs` persistence and schema version 4
- current/specific/all-run dashboard filtering
- exact SQLite run-scoped funnel counts, independent of the 5,000-row display cap
- same-block canonical V4 StateView screening
- route compression to the shortest common base instead of forcing ETH
- fee-aware marginal cycle edge
- hookless all-V4 verified path
- one canonical V4Quoter multi-hop closed-cycle quote
- current-block first probe rather than historical-screen-block quotation
- same-block base valuation through Par QuotePricer
- constant-product analytical sizing seed under strict reserve/liquidity assumptions
- exact 75/100/125% seed validation and deterministic eight-size fallback
- Verified Positive dashboard semantics requiring `verifiedClosedCycle=true`
- base/hop/truth metadata in dashboard candidates
- discovery decoupled from indexer `lastPriceEth` availability
- bounded `TRUTH_LAUNCH_LIMIT` and `TRUTH_SCAN_CONCURRENCY`

Economic-truth tests cover:

- rejection of unverified legacy positives from the green funnel.

## Green criterion

A candidate is green only when:
1. it forms a closed cycle beginning and ending in the same base asset,
2. every quoted hop is supported by the verified hookless all-V4 path,
3. canonical V4Quoter returns an amount-sensitive closed-cycle output,
4. the quote row is tagged `verifiedClosedCycle=true`,
5. paper net remains positive after the explicit research gas proxy, extra allowance and safety margin.

Indexer spread, marginal StateView edge, analytical seed output, or a legacy numeric quote cannot independently make a candidate green.

## Remaining limitations

1. **Gas is not atomic-executor gas.** V4Quoter's gas estimate with a 20% buffer is a research proxy.
2. **No execution contract exists.** The code cannot submit a trade, so atomic settlement and inclusion are not proven.
3. **V3/hooked routes are excluded from verified green.** This favors correctness over coverage.
4. **Public endpoint latency remains material.** A valid screen can disappear before the probe.
5. **ETH/USD is an external reporting input.** It does not affect the raw same-base cycle output but does affect USD paper-cost reporting.
6. **Analytical sizing is conditional.** It is a seed only and falls back to exact grid quoting.
7. **Historical LONG5 executable truth is still unavailable** without historical canonical pool state and routing/gas context.
8. **Positive samples do not establish expected profitability.** A meaningful independent sample and capture study remain necessary.

No wallet, key, signer, transaction submission, or automated execution capability was added.
