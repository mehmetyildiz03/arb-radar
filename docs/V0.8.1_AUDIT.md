# v0.8.1 Executable Truth audit

Date: 2026-09-27  
Branch: `v0.8.1-micro-sizing-audit`

## Trigger

The v0.8 dashboard showed hundreds of same-block candidates, enormous “truth spread” values and zero verified positives. First quote latency had already fallen to sub-second median territory, so the problem was no longer primarily speed.

The audit asked two concrete questions:

1. Does the old $1 minimum hide profitable sub-$1 sizes?
2. Why can StateView marginal edge be enormous while canonical V4Quoter output is negative or reverts?

## Exact size sweep

Public read-only canonical closed-cycle quotes were tested at:

`$0.01, $0.03, $0.10, $0.30, $1, $3, $10`

Eight scans produced:
- candidate observations: 48
- unique structural candidates: 6
- successful exact quotes: 64
- quote failures: 272
- gross-positive successful quotes: **0**
- verified paper-positive quotes: **0**

Best sampled net result was approximately **-$0.1564 at $0.01**.

Therefore lowering the minimum from $1 is useful for measurement completeness but does **not** explain the missing green in the sampled market state.

## Root cause of huge marginal edges

Per-hop StateView diagnostics found extreme examples with:
- Par buy active liquidity: `0`
- current tick: `887271`
- mathematically enormous slot0-derived spot rate

The exact micro quote did not reproduce that advantage.

Conclusion: slot0 price plus fee is not an executable marginal truth when current active liquidity is absent. A real amount must cross liquidity ranges; the canonical quoter is the correct arbiter.

Other candidates with positive active liquidity and apparently large spot edge reverted for every tested size. The outer V4Quoter error selector `0x6190b2b0` corresponds to `UnexpectedRevertBytes(bytes)`, meaning the quote simulation bubbled an underlying non-QuoteSwap revert. v0.8.1 adds the relevant V4Quoter error ABI so future failures are more legible.

## Correction

v0.8.1 changes candidate admission:

1. Build the supported hookless all-V4 closed cycle.
2. Read same-block StateView.
3. If active-liquidity spot state is reliable and marginal edge is nonpositive, reject cheaply.
4. If spot state is unreliable (including zero active liquidity), do not infer profitability from slot0.
5. Canonically quote a same-block micro closed cycle, default $0.01.
6. Admit only if raw same-base output is greater than raw same-base input.
7. Re-quote at the current block when capture begins.
8. If that first current-block quote is gross-negative, stop before sizing.
9. If gross-positive, exact-size from $0.01 upward and apply the existing paper cost model.

No research cost was removed and no green threshold was weakened.

## Post-fix public validation

After the correction, two independent scans each examined 26 recent launches.

Both returned:
- executable-truth candidates: 0
- selected candidates: 0
- quote failures in the downstream sweep: 0
- verified positives: 0

The old hundreds-of-candidates flood disappeared because those rows were not executable edges.

## Interpretation

A dashboard value of zero under **Micro-exact truth** is an honest result: no currently observed, supported hookless all-V4 closed cycle passed the executable gross-edge gate.

The correct response to sustained zero observations is not to relabel slot0 spreads as opportunities or delete gas/safety costs. The next research direction is broader verified route coverage and eventually executor-faithful atomic paper simulation.
