## Implemented

- viem 2.56.9 and Par SDK commit f5a5beb9f9efc17eaca0e2edf85648fa02bb2beb, with an HTTPS Git lockfile URL for installation without SSH credentials.
- Typed discovery, bounded metadata/route cache, independent directed markets, unequal-fee screening and stale/missing/invalid data rejection.
- Selected-market, amount-sensitive Par v4 router simulations, reference routing, raw bigint amounts, fixed block reads, reorg detection, gas estimation and explicit extra/safety costs.
- SQLite provenance on the six required tables plus sequencer observations; exact raw values and quote errors are retained.
- Lifecycle targets at 0/100/250/500/1000ms, actual start/completion timing, error-aware crossing and half-profit metrics. Every successfully sized candidate is followed, including a small input when no positive grid quote exists. Candidates whose simulation is unavailable are recorded as errors.
- Deterministic LONG5 replay, a verified sequencer decoder, bounded feed observation, next-block candidate preparation and log/RPC shadow-price reconciliation.
- Updated existing CI with Node 22/24, `npm ci`, typecheck/unit/fixture tests and replay reproducibility checks. No secrets.

## Audit fixes and remaining research limits

The audit tightened invalid/missing fee handling, reserved gas and extra costs inside the paper budget, rejected shared pools and hooks, checked reorgs, switched lifecycle scheduling to a monotonic clock, retained unknown samples instead of treating errors as zero profit, recorded actual RPC completion/error timing, and consolidated CI into the existing workflow.

No execution-boundary violation was found. These limitations are material and intentional:

1. Separate leg simulations are accepted only for disjoint, hook-free pools. A full stateful atomic simulator and atomic gas model remain outside this implementation. The 20% gas cushion, $0.05 extra allowance and 1% output margin are explicit assumptions, not proven worst-case bounds.
2. Public RPC latency can exceed the lifecycle target offsets. Samples record lateness; no subsecond opportunity persistence or capture capability was demonstrated. The size search precedes t0 and adds unmeasured discovery-to-capture delay.
3. LONG5 historical data supplies transaction-price screens, not historical executable depth, routing/gas quotes or subsecond observations. Best executable size, gross/net P&L, half-life and $100 capture feasibility are explicitly unknown in the report. No profitable strategy conclusion is supported.
4. The shadow experiment tracks pending relevance and reconciles observed Swap prices; it does not execute a speculative EVM before RPC. Deterministic reorg/mismatch tests passed, but the short live run contained no relevant pool event to validate that path live.
5. Feed signatures use a pinned public authority from the reference implementation. Authority rotation requires external verification and an update; unsupported formats and unverifiable frames fail closed. The feed remains an already-ordered observation, never a mempool.
6. Indexer observations without a block use null rather than an invented head number. Coinbase provides a timestamped reporting valuation, not an executable USD conversion. Data collection is a bounded cohort and not an exhaustive historical study.

The v0.2 code and bounded research experiments are implemented. Evidence required to promote to execution has not been established; mainnet execution remains absent.
