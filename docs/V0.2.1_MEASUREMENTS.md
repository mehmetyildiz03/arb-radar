# v0.2.1 measurement integrity — Issue #2

The lifecycle clock now starts at the original qualifying screen, before queueing, metadata, valuation, quoting or sizing. All launches in an indexer response are screened before slow candidate work. Each candidate retains its own `discoveredAtMs`.

The first small quote is attempted before the exhaustive eight-size search. The report persists `firstExecutableQuoteStartedMs`, `firstExecutableQuoteCompletedMs`, success/failure, `sizingStartedMs`, `sizingCompletedMs` and `postSizingLifecycleStartedMs`. Derived durations separate discovery-to-first-quote from sizing and post-sizing measurement. Preparation failures leave quote/sizing timestamps null; attempted quote and sizing failures retain their measured start/end times.

Targets 0/100/250/500/1000ms stay relative to discovery. Every sample records its absolute deadline, discovery-relative start/completion and missed-start deadline duration. Calls remain serialized. After sizing, late observations are labeled late, never relabeled t0. The original probe input stays fixed across lifecycle samples so size changes cannot masquerade as price decay. The optimizer's best size is a separate paper result.
